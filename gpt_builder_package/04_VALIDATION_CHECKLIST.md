# 개인용 헌법 GPT 검증 체크리스트

## A. Builder 입력 확인

- [ ] 이름이 헌법 학습 목적을 명확히 드러냄
- [ ] 설명이 한 과목 장기학습, OX, 판례 연결, 저장·복원을 포함함
- [ ] `01_BUILDER_INSTRUCTIONS.txt` 전체를 지침 칸에 붙여 넣음
- [ ] 대화 스타터 4개를 각각 입력함
- [ ] 구형 `cc_canvas.md`를 업로드하지 않음
- [ ] 최신 `M_C_canvas_engine.prompt.txt`만 업로드함
- [ ] 저장·복원 이중 구조 v2를 업로드함
- [ ] 헌법 프로젝트 지침과 채팅 분할표를 업로드함
- [ ] 교재 또는 목차·판례 색인을 업로드함
- [ ] 이미지 생성 기능을 끔
- [ ] 웹 검색과 코드 인터프리터를 켬

## B. 미리 보기 기본 응답 시험

다음 문장을 입력한다.

“POINT와 페이지를 주지 않았어. 현재 범위를 추정하지 말고 무엇이 필요한지만 말해.”

통과 기준:

- 임의 페이지나 POINT를 만들지 않음
- 필요한 체크포인트 또는 범위를 짧게 요청함
- 전체 캔버스를 만들지 않음

## C. 복원 zero-beat 시험

`knowledge/07_quick_checkpoint_example.json` 내용을 붙여 넣고 다음 문장을 함께 보낸다.

“이 체크포인트를 복원만 해. 새 수업은 시작하지 마.”

통과 기준:

- 현재 범위, 활성 약점, 미해결 문제, 다음 행동만 확인
- 진도 증가 없음
- 새 문제 출제 없음
- canvas_id와 revision을 임의 변경하지 않음

## D. .cc 최초 생성 시험

복원 성공 후 입력한다.

“.cc 현재 범위의 전체 구조를 핵심 연결 위주로 만들어 줘.”

통과 기준:

- 완전한 HTML 문서 하나와 나침반만 출력
- unit-header, key-terms, concept-map, case-map, weakness-list, next-action 존재
- revision 1 또는 복원된 유효 revision 사용
- 동일 단원의 전체 백업 JSON이나 과거 아카이브를 본문에 넣지 않음
- 이미지 모드가 꺼져 있으므로 자동 이미지 생성 없음

## E. .cu 부분 갱신 시험

일반 Markdown 학습을 한 번 진행한 뒤 입력한다.

“.cu 방금 새로 확인된 판례 연결과 약점만 반영해.”

통과 기준:

- 전체 강의 HTML을 반복하지 않음
- 변경된 section만 patch 배열에 포함
- canvasId 유지
- baseRevision과 nextRevision이 연속
- 변경되지 않은 section 미포함

## F. .cv 읽기 전용 시험

입력한다.

“.cv”

통과 기준:

- 최신 저장 revision 표시
- 새 설명·문제·약점 재계산 없음
- revision 증가 없음

## G. .cs snapshot 시험

입력한다.

“.cs”

통과 기준:

- 최신 revision을 먼저 view
- snapshotId와 checkpointId 연결
- 학습 진도 변화 없음
- Ailey’s Note 아카이브가 생성되거나 저장 가능한 화면이 열림

## H. 저장·복원 드리프트 시험

1. `저장` 실행
2. 새 채팅 생성
3. 저장 패킷 복원
4. 아무 학습도 하지 않고 다시 `저장`

통과 기준:

- 완료 POINT 동일
- 활성 약점 동일
- 미해결 문제 동일
- 다음 행동 동일
- 메뉴 바인딩 동일
- canvasId와 revision 동일
- saved_at과 새 checkpoint_id만 변경 가능

## 최종 판정

A∼H가 모두 통과하면 `나만 사용`으로 생성한다. 하나라도 실패하면 기능을 추가하기 전에 지침·지식 파일 중복과 구형 캔버스 파일 존재 여부부터 점검한다.
