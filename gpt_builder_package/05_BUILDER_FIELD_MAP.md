# 지금 Builder 화면에 입력할 값

## 1. 이름

헌법 Ailey & Bailey — 김건호 비헌기OX 장기학습

## 2. 설명

김건호 헌법 비헌기OX 교재를 중심으로 POINT·페이지 진도, 판례 연결, OX 채점, 약점, 빠른 체크포인트, Ailey’s Note 아카이브와 부분 갱신 캔버스를 관리하는 개인용 헌법 장기학습 GPT

## 3. 지침

`01_BUILDER_INSTRUCTIONS.txt`의 전체 내용을 복사해서 지침 칸에 붙여 넣는다.

주의:

- 기존 지침이 들어 있다면 모두 지운 뒤 새 지침 하나만 넣는다.
- `M_C_canvas_engine.prompt.txt` 전체를 지침 칸에 추가로 붙이지 않는다.
- 캔버스 상세 규격은 지식 파일로 업로드하고, 지침에서는 그 파일을 구속력 있는 실행 규격으로 호출한다.

## 4. 대화 스타터

`02_CONVERSATION_STARTERS.txt`의 네 문단을 각각 별도의 스타터로 입력한다.

## 5. 지식

파일 업로드 버튼을 누르고 `03_KNOWLEDGE_UPLOAD_MANIFEST.md`의 필수 6개를 업로드한다.

한 번에 여러 파일을 선택할 수 있지만, 업로드 완료 표시가 뜬 뒤 다음 설정으로 이동한다.

## 6. 권장 모델

- 드롭다운에 빠른 일반 모델이 있으면 속도 우선으로 선택
- 현재 화면처럼 `Thinking 5.6`만 확실하게 보이면 그대로 유지
- 모델은 사용자가 채팅에서 바꿀 수 있으므로 이 설정 하나로 학습 전체가 고정되지는 않음

## 7. 기능

| 화면 항목 | 설정 | 이유 |
|---|---|---|
| 웹 검색 | 켜기 | 최신 법령·판례를 요청받았을 때만 사용 |
| 이미지 생성 | 끄기 | 헌법 학습과 캔버스 응답 속도 우선 |
| 코드 인터프리터 및 데이터 분석 | 켜기 | 첨부 파일·데이터·생성 파일 처리 지원 |
| Canvas | 보이면 켜기 | 네이티브 문서 편집용, 사용자 정의 `.cc`와는 별도 |
| 앱 | 처음에는 없음 | 원인 분리가 쉬움 |
| Actions | 처음에는 없음 | 현재 런타임은 CDN HTML 방식이므로 필수 아님 |

나만 사용

공개 링크나 GPT Store 배포는 헌법 학습 데이터와 개인 진도가 안정적으로 분리된 뒤에만 고려한다.

## 9. 만든 뒤 헌법 프로젝트에서 사용

1. 새 헌법 프로젝트를 만든다.
2. 프로젝트 설정에 `knowledge/03_constitution_project_instructions.md` 내용을 넣는다.
3. 교재, 분할표, 최신 빠른 체크포인트를 프로젝트 파일로 둔다.
4. 프로젝트 안에서 새 일반 채팅을 먼저 시작한다.
5. 그 채팅에서 개인용 헌법 GPT를 호출한다.
6. 첫 메시지는 빠른 체크포인트 복원만 수행한다.
