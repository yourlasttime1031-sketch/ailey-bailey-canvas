# 헌법 장기학습 통합 운영 매뉴얼

## 1. 최종 구조

### 프로젝트

헌법 한 과목의 공통 문맥을 보관한다.

프로젝트에는 다음만 둔다.

- 교재 PDF 또는 필요한 목차·범위 파일
- 헌법 34개 채팅 분할표
- 최신 빠른 체크포인트
- 판례·출처 색인
- 프로젝트 지침

과거 모든 단원 아카이브를 프로젝트 파일로 각각 올리지 않는다.

### 단원별 채팅

현재 학습 작업을 담당한다.

한 채팅은 분할표의 한 단위를 원칙으로 한다. 매우 짧으면 인접 단위를 묶을 수 있지만, 자유권·국회·헌법소원처럼 심사구조가 다른 범위를 한 채팅에 과도하게 합치지 않는다.

### Ailey’s Note

상세 아카이브와 캔버스 스냅샷을 보관한다.

Ailey’s Note는 과거를 찾는 장소이지 매 턴 모델에 전부 주입하는 장소가 아니다.

### 빠른 체크포인트

현재 책갈피다.

새 채팅에서는 이것만 복원하고, 상세 과거가 필요할 때 해당 단원 아카이브를 선택적으로 추가한다.

## 2. 새 프로젝트 시작

a. “헌법 장기학습 — 김건호 비헌기OX” 프로젝트 생성
b. 가능하면 프로젝트 전용 메모리 선택
c. 교재와 03 프로젝트 지침 업로드
d. 04 채팅 분할표를 프로젝트 소스로 저장
e. 프로젝트 안에서 일반 채팅을 먼저 생성
f. 그 기존 프로젝트 채팅에서 Ailey & Bailey GPT 사용
g. 최신 빠른 체크포인트 복원
h. 05 검증 프로토콜의 시험 B 수행

## 3. 한 채팅의 표준 수명주기

### 시작

- 빠른 체크포인트 복원
- POINT·페이지 확인
- 미해결 문제 여부 확인
- 새 학습 없이 상태 확인

### 지도

- 필요하면 .cc 한 번
- 캔버스는 현재 단원의 개념 구조와 판례 연결만 표시

### 학습

- 일반 Markdown으로 개념 설명
- OX 지문 분석
- 판례 비교
- 문제 풀이와 채점
- 약점 정규화

### 갱신

- 중요한 연결 묶음이 끝날 때 .cu
- 화면만 다시 볼 때 .cv
- 매 문답마다 .cu를 호출하지 않음

### 종료

- 범위 완료 확인
- 대표 약점과 다음 단원 연결 정리
- .cs 실행
- 빠른 체크포인트 저장
- 필요하면 단원보관
- 다음 분할 채팅 생성

## 4. 속도 우선 모델 운용

빠른 문답과 OX 분석은 모델 선택기에서 Instant 또는 낮은 사고 수준을 우선한다.

다음 작업에만 높은 사고 수준을 사용한다.

- 복수 판례의 충돌 구조
- 위헌심사 기준 비교
- 헌법소원 적법요건 종합
- 국회·정부·헌재 권한 관계
- 오답 원인의 구조적 진단
- 프로젝트 전체 재설계

모델을 바꾼 뒤에는 Canvas 지원 여부가 달라질 수 있으므로 화면 기능은 실제 선택기 표시를 확인한다.

## 5. 캔버스 구현

현재 사용자 Fork의 런타임 v2에는 create, patch, view, snapshot, reset 연산, stable canvas_id, revision 충돌 검사, localStorage 또는 메모리 저장, patch_id 중복 방지와 실패 시 DOM 롤백이 구현되어 있다.

- .cc 전체 단원 캔버스
- .cu 실제 변경 section 부분 갱신
- .cv 저장본 보기
- .cs 스냅샷

## 6. 권장 저장 주기

- 학습 중 중요한 변화: 빠른 체크포인트
- 분할 채팅 종료: .cs와 단원보관
- PART 종료: 전체 백업 JSON
- 주 1회: 로컬 외부 위치에도 전체 백업
- 브라우저 초기화·기기 변경 전: 전체 백업과 복원 시험

## 7. 프로젝트 파일 관리

Plus 프로젝트에는 다음 역할만 고정한다.

- 교재
- 프로젝트 지침
- 채팅 분할표
- 최신 빠른 체크포인트
- 판례 색인
- 시험·점수 요약
- 현재 학습에 필요한 소수 자료

과거 체크포인트와 단원별 상세 아카이브는 Ailey’s Note에 두고 프로젝트 파일을 계속 늘리지 않는다.

## 8. 현재 상태에서의 전환안

화면에 보이는 486∼503쪽 평등권 판례 연결학습이 실제로 끝났다면 다음과 같이 한다.

a. 기존 채팅에서 .cs
b. “헌법-11-II03-평등권-P104-108” 단원보관
c. 전체 백업 JSON 갱신
d. 헌법 프로젝트 안에서 새 일반 채팅 생성
e. 개인용 헌법 GPT 호출
f. 최신 빠른 체크포인트 복원
g. “헌법-12-II04-생명·신체·형사절차-P109-126”으로 제목 변경
h. 504쪽 POINT 109부터 학습 시작
i. 필요할 때 .cc로 자유권 첫 캔버스 생성

## 9. 성공 기준

- 새 채팅 첫 복원이 짧고 빠름
- 교재 범위와 약점이 정확함
- 캔버스를 자주 열어도 전체 강의를 반복 생성하지 않음
- 과거 상세 기록은 검색 가능함
- 전체 백업으로 새 기기 복구가 가능함
- 저장·복원만으로 진도와 숙달도가 변하지 않음
- 분할 채팅을 바꿔도 한 과목의 경로가 이어짐
