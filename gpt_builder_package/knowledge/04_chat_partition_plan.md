# 김건호 헌법 비헌기OX 목차 기준 채팅 분할표

## 분할 원칙

- 한 채팅은 하나의 심사구조, 제도 또는 밀접한 판례군을 담당한다.
- 짧은 장은 인접 장과 묶고, 자유권·국회·헌법소원처럼 큰 장은 세분한다.
- 각 채팅에서 전체 캔버스는 원칙적으로 한 번만 만든다.
- 목차의 빈출등급 S·A·B·C는 채팅 분할 기준이 아니라 해당 채팅 안의 학습 우선순위로 사용한다.
- 페이지와 POINT는 첨부 교재 목차 5∼10쪽을 기준으로 했다.
- PART II CHAPTER 08 국민의 기본의무는 목차 이미지에 세부 POINT가 표시되지 않아 1035∼1049쪽 범위로 별도 표시했다.

## 현재 위치에서의 권장 전환

현재 Ailey’s Note 화면에는 486∼503쪽 평등권 판례 연결지도가 보인다. 이 범위가 완료된 상태라면 기존 긴 채팅은 연번 11의 종료 아카이브로 확정하고, 새 프로젝트 채팅은 다음 이름으로 시작한다.

헌법-12-II04-생명·신체·형사절차-P109-126

첫 메시지는 빠른 체크포인트 복원만 수행하고, 두 번째 메시지에서 504쪽과 POINT 109 시작 여부를 확인한다.

## 캔버스 사용 횟수

각 채팅 권장 상한:

- .cc 전체 생성 1회
- .cu 부분 갱신 1∼3회
- .cv 읽기 전용은 필요할 때
- .cs 종료 스냅샷 1회

이 상한을 넘기거나 체감 지연이 생기면 같은 PART 안에서도 다음 분할 채팅으로 이동한다.
