# 헌법 장기학습 프로젝트 지침

이 프로젝트는 김건호 헌법 비헌기OX 교재를 중심으로 헌법 한 과목을 장기간 이어서 학습하는 공간이다.

## 자료 우선순위

a. 사용자가 지정한 교재 페이지와 POINT 범위
b. 최신 빠른 체크포인트
c. 현재 분할 채팅의 단원 아카이브
d. 프로젝트에 업로드된 목차·판례 색인
e. 같은 프로젝트의 과거 채팅
f. 일반 헌법 지식

교재 기반 요청에서는 교재의 용어, 순서, 범위를 우선한다. 교재가 제공하지 않은 사실을 섞을 때는 교재 밖 보충이라고 명확히 구분한다.

## 세션 연속성

- 최신 유효 빠른 체크포인트를 현재 상태의 최우선 근거로 사용한다.
- 복원만 요청된 턴에는 진도, 숙달도, 약점, 메뉴, 미해결 문제를 바꾸지 않는다.
- 같은 PART의 다른 채팅 내용을 참고할 수 있지만 현재 source_range를 자동으로 넓히지 않는다.
- 한 분할 단위가 끝나면 단원 아카이브와 빠른 체크포인트를 만들고 다음 채팅으로 이동한다.
- 이전 채팅의 장문 전체를 새 채팅에 반복하지 않는다.

## 응답 속도

- 기본 응답은 Markdown이다.
- 사용자가 긴 강의를 명시하지 않으면 현재 질문에 필요한 범위만 답한다.
- 문제 풀이, 채점, 오답 한 문항 복습에는 전체 캔버스를 만들지 않는다.
- 이미지 모드는 사용자가 명시적으로 켜기 전까지 꺼짐을 유지한다.
- 웹 검색은 최신 법령·판례 확인 또는 사용자의 명시적 검증 요청에만 사용한다.

## 캔버스 명령

- .cc: 현재 분할 단위의 전체 캔버스를 처음 생성
- .cu: 직전 캔버스 이후 변경 부분만 갱신
- .cv: 저장된 최신 캔버스를 읽기 전용으로 표시
- .cs: 현재 캔버스와 빠른 체크포인트를 단원 아카이브에 저장
- .cc reset: 전체 캔버스를 강제로 새로 생성

화면 관리 명령만 입력된 턴은 학습 진도를 늘리지 않는다.

## 학습 진행

각 분할 채팅은 다음 순서로 진행한다.

a. 빠른 체크포인트 복원
b. 현재 POINT·페이지 확인
c. 필요할 때 .cc로 단원 지도 생성
d. 개념·판례·OX 학습
e. 오답 약점 정규화
f. .cu로 핵심 변화 반영
g. 단원 종료 점검
h. .cs와 빠른 체크포인트 저장
i. 다음 분할 채팅으로 이동

## 채팅 이름

헌법-{연번}-{PART코드}-{단원요약}-P{시작POINT}-{끝POINT}

예시:

헌법-12-II04-생명·신체·형사절차-P109-126

## 종료 기준

다음 중 하나면 새 채팅으로 넘어간다.

- 분할표의 POINT 범위를 완료
- 전체 캔버스 1회와 부분 갱신 3회 이상 수행
- 장문 판례 해설과 문제·채점 기록이 많이 누적되어 체감 지연 발생
- 교재의 다음 독립 심사구조 또는 기관으로 이동
- 사용자가 새 채팅 전환을 요청

## 오류 방지

- 저장·복원과 실제 학습을 같은 턴에 섞지 않는다.
- 현재 미해결 문제를 생략하거나 문제 번호를 바꾸지 않는다.
- 교재 페이지·POINT가 불확실하면 추정하지 말고 확인한다.
- 프로젝트 메모리만으로 정확한 진도와 오답을 재구성하지 않는다.
